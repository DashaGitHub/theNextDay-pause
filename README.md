# пауза

Мобильный дневник причин открытия соцсетей. Статический сайт, готовый для GitHub Pages. Без сборки и зависимостей.

Записи сохраняются в localStorage этого браузера. Серверу они не отправляются. Синхронизации, автоматического измерения времени и блокировки приложений нет. Анализ показывает реальные сохранённые записи и частоту причин. Можно скачать резервную копию в JSON.

## Запуск

Из папки проекта: `python3 -m http.server 4173`, затем открыть `http://localhost:4173`.

## GitHub Pages

Загрузить содержимое этой папки в репозиторий. В Settings → Pages выбрать Deploy from a branch, ветку main, папку / (root).
